# 备考有方 · 白板修订原型

直接用浏览器打开 [index.html](index.html)。原型使用静态文件，支持离线运行。登录页可选择体验学员、维护者或管理员。演示账号、目标、草稿、答卷、照片与发布操作保存于当前浏览器。

[逐页需求与验收](../../docs/PRD-whiteboard.md) · [原型修改记录](../../CHANGELOG.md)

正式工程 `v0.3.0-alpha.1` 已接入账号目标、单题作答、自评和复练。独立原型继续离线使用，记录保存在原浏览器。两者的覆盖范围见[正式工程需求](../../docs/PRD.md)。

## 原型 2.25 · 黑白漫画角色

登录区外围使用水豚、野兔、獾和河狸。桌面与手机首页标题右侧均只显示章鱼。窄屏登录保留水豚和河狸。

## 原型 2.23 · 到期复练

1. 以体验学员设置考试日期。在 P07 给简答选择「想不起来」或「有点模糊」，分别安排隔 1 天或 3 天的复练。可选填一个想补的要点，回首页可查看最近一次安排。
2. 到期后从 P02 进入。优先使用同主题的另一道题。复练有独立草稿，写完简答可回填该要点是否独立写出。P02 的已练项计一次自评，知识页继续显示实际选择的掌握度。
3. P13 正常交卷从实际作答且已评分的失分题中列出至多两个主题。点「安排复练」后回首页查看。纸笔模式从本卷手动选题，手填总分只保存成绩。
4. P09 新卷标为限时练习，三档建议用时沿用教学估算。P02 和 P07 可展开范围与依据。

重建独立 HTML 使用 `node scripts/build-whiteboard-prototype.ts`。验证使用 `node scripts/test-whiteboard-review-loop.ts`，测试将浏览器前进到复练到期日。带 `--capture` 时重采 PRD 标注截图。原型数据依旧按体验账号保存在当前浏览器。

## 体验路径

1. 选体验学员，设置考试日期和每日时长。开始今日任务，核对并自评，回首页和知识地图查看进度。
2. 在题目练习筛选题型或薄弱状态，选择原题或变式。用错题集查看已发生的练习和模拟错题。
3. 打开模拟考试，生成系统推荐的试卷。可继续草稿、打印空白卷、上传纸笔答题照片或在线作答。交卷后逐题人工评阅，再从答题记录查看本次复盘。
4. 切换维护者，编辑四类题并预览，保存草稿或发布。时政材料需手动核验后才出现在学员空间。
5. 切换管理员，开通或启停演示账号。

模拟卷支持 20、40、60 分钟三档，按每日复习时长推荐并可手动切换。目标题数为 10、20、30 题，选择/判断/填空/简答配比为 4/2/3/1 并按档位倍增。选择、判断的基础题数为该型题量除以 4 后向下取整，其余为辨析题（4 道选择即 1 基础 + 3 辨析）。难度不足时按实际池补足并提示。每次随机抽题，优先避开上一套，生成后固定快照；旧草稿保留原题量。空白卷按题型分区，适配 A4。难度是编题预设，建议时长尚未用真实作答数据校准。

P10 提供「放弃作答，直接查看答案」，确认后保留原答、结束本次在线作答，生成「已看答案 · 纸笔自核」记录，显示全部参考答案并支持 A4 打印/保存 PDF、独立 HTML 导出。原始总分可在 P12/P13 手填，支持 0 分、范围检查与清除；不会由缺失作答推断错题。

P12 采用整卡可点的纸质答卷卡，复用浅灰悬停和按压效果；手填成绩表单位于链接上方，不触发跳转。成绩显示朱红手写百分制整数，保留原卷得分与满分。真正满分才出现原创立体火漆章，四舍五入到 100 不额外获章，纸笔手填满分明确标注成绩来源。见[素材与生成提示词](full-marks-seal-v2.md)。数字字体为内置 [Patrick Hand](https://github.com/google/fonts/tree/main/ofl/patrickhand)，附 [OFL 许可证](fonts/OFL-PatrickHand.txt)，离线可用。

知识卡教学题现为 46 道单选、46 道判断、23 道填空，覆盖 23 张知识卡。单选保留 12 基础、升级 34 辨析；判断 23 基础 + 23 辨析。辨析选项取自相邻要点，并保存两处原文与差别说明，不引入外部知识或政策。完整题干、答案和依据见[编制清单](../../docs/知识点客观题编制清单.md)。重建：`node scripts/build-whiteboard-questions.ts`；生成独立 HTML：`node scripts/build-whiteboard-prototype.ts`；验证：`node scripts/test-whiteboard-exams.ts` 和 `node scripts/test-whiteboard-answer-export.ts`。旧浏览器追加缺失题目，仅升级完整匹配的内置旧题，不覆盖用户修订、下架状态、进行中与已交卷快照。

纸笔照片支持 PNG、JPEG、WebP，每题一张，单张最多 1 MB。浏览器容量不足时会提示。打印页面可下载独立 HTML，也可通过浏览器打印为 PDF。

原型对应白板修订需求，用于浏览器内功能验收。正式运行仍由 alpha.3 的服务端提供账号与题库能力。

P07 简答页取消「对照参考自评」按钮及独立参考区，完整要点统一放在第三层提示中，补充解析和已审核材料也归入提示，避免重复正文；客观题保留「核对答案」。三个熟练度选项始终显示，未输入、未看提示也可直接自评。直接自评不生成客观 0 分或满分，同次作答改选熟练度更新同一条记录，旧历史保留。功能验证：`node scripts/test-whiteboard-practice-self-assessment.ts`。

## 知识卡数据

P04 的 S、A、B 入口使用整卡链接，点击空白处或进度条也可进入对应主题组。卡片动效预设为 `card-motion`，包含暖白默认态、浅灰上浮悬停态、浅绿下压点击态，并支持键盘焦点和减少动态效果设置。后续可在指定的卡片链接上添加同名类复用，具体采用范围由用户确认。

P06 的原题卡复用同一动效，整卡点击进入原题，变式行独立进入变式。默认仍按掌握程度显示各自底色。

题目与材料通过 `contentType` 区分，题目再以 `questionRole` 和 `parentId` 标记原题/变式。当前题库有 181 道题目，材料库有 18 条知识讲解和 6 条待核验政策引用。知识卡和题目通过 `explanationRefs`、`policyBasisRefs` 引用材料。政策引用从维护端「原始政策依据」登记核验。旧浏览器题库按明确的旧版本记录自动追加分类修订，个人答题与旧答卷快照保留。

[data.js](data.js) 中的 `knowledgeCards` 保存 23 张知识卡、109 个记忆点。每个记忆点包含固定编号、速记提示 `cue`、简短表达 `summary` 和完整解释 `detail`。主题通过 `knowledgeId` 引用知识卡，P05 卡片、P07 提示和知识提纲共用这些内容。简短表达为原型展示整理，完整解释和主题核心句保留原文。

从「知识学习」选择 S 级并展开主题组，可以直接点选「保 生命优先」等速记段查看解释。多字提示和 3 至 7 点的主题使用相同结构，窄屏自然换行。后续维护导入格式见 [PRD 的知识库数据约定](../../docs/PRD-whiteboard.md#知识库数据约定)。

P05 每个主题单独显示一条下拉栏，掌握标签固定在标题右侧，收起时仍可见；双主题组分别显示各自状态。整条按未接触暖白、待自评浅蓝、想不起来浅红、有点模糊暖黄、能独立回忆浅绿着色。标题行支持浅灰悬停、按压、焦点框和约 240ms 的展开/收起动画，支持快速反向点击、Enter/空格、减少动态效果。内层速记段、完整解释及自测入口保持原有操作。功能验证：`node scripts/test-whiteboard-knowledge-disclosure.ts`。

P05 的本级进度取消整行外框，在页标题同行居中显示不超过 280px 的短条；多邻国风格纯亮绿填充、浅灰轨道和轨道轻阴影，填充不做渐变或内部高光与掌握度色卡区分。手机上移至标题下方居中，统计口径不变。

知识地图的「打印或下载知识提纲」支持按主题、优先级、关键词和掌握情况筛选。点击应用后自动勾选全部匹配知识点，可手动取消或清空。每条知识点对应完整知识卡。打印使用一行标题加连续正文，速记字加大加粗，支持主题分类、优先级、薄弱优先和标题排序。独立 HTML 沿用相同内容和版式。
