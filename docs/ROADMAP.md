## 每个业务模块的接入方法

先写数据迁移与接口契约，随后实现服务器校验、权限和事务，再替换对应前端本地状态，并执行真实数据库集成测试。一个模块接入完成后再切换数据来源，不让同一页面同时写入本机和服务器而造成分叉。

## 关键验收场景

- 新账号不会出现他人练习记录；学员调用维护 API 必须被服务器拒绝；退出和过期会话失效。
- 维护者发布的选择/判断/填空/简答可在另一账号看到；草稿和归档不会出现在用户列表；原题下的变式关系正确。
- 两名维护者同时编辑时通过 expectedVersion 拒绝覆盖更新；已作答题目改版后旧答卷仍可阅读旧题与旧参考。
- 仅打开题目不能自动改变为已掌握；评分对错和自评颜色独立；题目列表支持薄弱题筛选。
- 跨日、考试当天是否计入、过去日期和每日时长计算保持原型行为；已完成时数与计划容量分开。
- 模拟答卷重复交卷不产生两次记录；未交卷无复盘；待主观评阅不显示最终成绩。
- 时政来源未核验不得发布；政策失效后可定位受影响题目，新版不覆盖基础答案和旧作答。
- 在干净服务器按文档拉取指定 tag 并启动；从备份恢复后记录完整；升级后健康检查与版本相符。
