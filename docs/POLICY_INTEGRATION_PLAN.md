# 时政与政策融入题库的功能规划

目标是在不推翻已有知识结构的前提下，让有依据、适用的政策表述进入对应题目的参考答案。政策事实必须独立核验，当前不预置未经验证的“最新政策”。

一期优先处理正式政策文件。时事事件、会议报道和教育热点可作为案例素材另行归档，记录事实、发生时间、报道来源及可迁移主题；不能把报道或案例观点直接标成政策要求。对同一题可分别关联“规范依据”和“案例应用”，避免两类证据混用。

## 三类数据

1. 政策资料：文件全称、发文单位、发布日期、原文链接、原文摘录、适用地区/对象、生效与失效时间、来源核验记录、复核日期、状态。
2. 题库内容：稳定题号、题型、题干、主题、基础参考答案、正确答案或评分要点、资料性质、内容版本、发布状态。
3. 融合关系：政策ID与版本、题目ID与版本、基础答案中的具体锚点、插入位置、增补句、适用范围、引用段落、审核人/时间、状态。

政策与题目是多对多关系。不要把政策直接复制进所有答案，也不要因同一政策关联多个主题而重新生成一整套记忆口诀。

## 维护过程

录入原文资料 → 核验名称、发布单位、原文与适用期 → 选择相关考点/题目 → 确定原答案位置 → 编写一条有针对性的增补表达 → 对比旧答案与新增句 → 人工审核 → 发布融合关系。

草稿、待核验、待审核、已发布、已停用应独立显示。未核验不能转为可见融合内容；题目或政策版本变化后原审批不沿用，关系退回待复核。来源链接存在不等于已核验，最终需要核对内容是否支持新增表述。

## 按题型处理

| 题型 | 融合方式 | 质量检查 |
| --- | --- | --- |
| 选择 | 将政策应用写入情境或选项；必要时建立新版题目 | 依据是否仍支持正确选项，其他选项是否构成歧义 |
| 判断 | 更新命题与判断依据 | 发文时间、适用对象和限定条件不能丢失 |
| 填空 | 维护原文允许表述、逐空答案和可接受同义项 | 与原文对应，不能用模糊关键词匹配替代答案 |
| 简答 | 保留基础知识答案与按钮，在明确段落后增加政策表达 | 切题、具体行动、引用依据和适用边界明确，避免套话 |

客观题的政策变化可能改变正确答案，必须重新命题/核对而非只加一句“结合时政”。简答题可以使用定位式增补，但新增政策表述不自动等于必得分项；评分依据需另行审核。

## 学员端的层级

题目 → 作答 → 基础参考答案 → 可展开的“结合当前政策” → 新增句、来源与适用范围。

原答案保持可见，新增句使用文字标签而非只靠颜色。学员可以知道“在原答案哪一段后面加什么”；不强制学习一套与已有知识脱节的新答案。用户未提交作答前不泄露参考答案。

## 更新、冲突与追溯

- 新旧文件冲突时暂停相关融合关系，列出受影响题目与模拟卷，人工复核后发布新版本。
- 到复核时间或原文失效后给维护者提示，不能继续标为“当前有效”。
- 修订保留旧版本、修改理由及依据。既往答卷引用当时的题目与评分版本，不用新政策追溯重算旧成绩。
- 原文片段与教学改写分开存储，改写不能被当作原文引用。

## 当前原型与下一阶段

当前提供时政融合规划界面、可填写的融合草稿、插入位置选择和学员端效果预览；所有草稿标为待核验，不进入学员端。没有模拟真实核验或AI政策生成。

正式运行前需接入共享题库/政策库、维护人员身份与权限、审批日志、发布事务、版本快照、到期复核和备份。日常新增题目可以由编辑完成；政策核验与发布建议保留明确人工责任。
